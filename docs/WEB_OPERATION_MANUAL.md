## 1. 起動方法

### ローカル開発環境

```bash
# 1. リポジトリ取得
git clone https://github.com/tao-munakata/affibase
cd affibase

# 2. 環境変数ファイルを作成
cp .env.example .env
# .env に ANTHROPIC_API_KEY などを設定

# 3. 全サービス起動
docker compose up -d

# 4. 起動確認
docker compose ps
```

### アクセス先URL

| サービス | URL | 備考 |
|---|---|---|
| PF管理画面 (Next.js) | http://localhost:3000 | 会員ダッシュボード |
| バックエンドAPI (Hono) | http://localhost:3001 | REST API |
| 会員サイト (Astro) | http://localhost:4321 | 生成済みサイトプレビュー |
| PostgreSQL | localhost:5432 | DB直接接続時 |

## 2. 画面一覧と基本操作

### 2-1. トップ / リダイレクト画面

- **URL:** `http://localhost:3000/`
- **表示内容:** ログイン済みの場合は `/dashboard` に自動リダイレクト
- **未ログイン時:** `/login` にリダイレクト
- **遷移先:** ログイン画面 / ダッシュボード

---

### 2-2. ログイン画面

- **URL:** `http://localhost:3000/login`
- **表示内容:** AffiBase ロゴ、メールアドレス入力欄、パスワード入力欄、ログインボタン、新規登録リンク

#### 入力項目

| 項目 | 必須 | バリデーション |
|---|---|---|
| メールアドレス | ○ | メール形式 |
| パスワード | ○ | 8文字以上 |

#### 操作手順

1. メールアドレスを入力する
2. パスワードを入力する（8文字以上）
3. 「ログイン」ボタンをクリック
4. 成功時 → `/dashboard` に遷移
5. 失敗時 → 画面内にエラーメッセージを表示

#### エラー表示

- メールアドレス形式不正: `正しいメールアドレスを入力してください`
- パスワード8文字未満: `8文字以上で入力してください`
- 認証失敗: `ログインに失敗しました` (赤背景ボックス)
- メール未登録 / パスワード不一致: APIから `401 Unauthorized`

---

### 2-3. 新規登録画面

- **URL:** `http://localhost:3000/register`
- **表示内容:** 名前・メールアドレス・パスワード入力欄、登録ボタン、ログインリンク

#### 入力項目

| 項目 | 必須 | バリデーション |
|---|---|---|
| 名前 | ○ | 1〜100文字 |
| メールアドレス | ○ | メール形式 |
| パスワード | ○ | 8文字以上 |

#### 操作手順

1. 名前を入力する
2. メールアドレスを入力する
3. パスワードを入力する（8文字以上）
4. 「登録する」ボタンをクリック
5. 成功時 → JWT取得 → `/dashboard` に遷移
6. 失敗時 → エラーメッセージを表示

#### エラー表示

- 既存メールアドレス: `このメールアドレスはすでに登録されています` (APIから `409 Conflict`)
- その他エラー: `登録に失敗しました`

---

### 2-4. ダッシュボード画面

- **URL:** `http://localhost:3000/dashboard`
- **認証:** ログイン必須（未ログイン時は `/login` にリダイレクト）
- **表示内容:** 統計カード4種、収益推移グラフ、クイックアクションリンク

#### 表示される統計カード

| カード | データソース |
|---|---|
| 総PV数 | `GET /api/v1/reports/summary` |
| アフィリエイト収益 | 同上 |
| 成約件数 | 同上 |
| AI引用回数 | 同上 |

#### 操作できること

- 「テーマを選ぶ」→ `/themes` に遷移
- 「サイト管理」→ `/sites` に遷移
- 「案件を見る」→ `/offers` に遷移
- 「レポート」→ `/reports` に遷移
- サイドバーの各メニューをクリックして遷移

---

### 2-5. テーマ選択画面

- **URL:** `http://localhost:3000/themes`
- **認証:** ログイン必須
- **表示内容:** ジャンルフィルター、テーマカード一覧（検索数・競合・単価・難易度スコア表示）

#### 操作手順

1. ジャンルタブ（すべて / 副業 / 転職 / AIツール / オンライン学習 / 投資）でフィルター
2. 検索ボックスでテーマ名を絞り込む
3. テーマカードの詳細情報（月間検索数・競合難度・平均案件単価・AEOポテンシャル）を確認
4. 「このテーマで始める」ボタンをクリック
5. → `/sites/new?theme_id={id}&theme_name={name}` に遷移

#### フィルター動作

- ジャンル選択: `GET /api/v1/themes?genre={ジャンル名}`
- テーマ未選択時: 月間検索数降順で全件表示

---

### 2-6. サイト新規作成画面

- **URL:** `http://localhost:3000/sites/new?theme_id={uuid}&theme_name={name}`
- **認証:** ログイン必須
- **前提:** テーマ選択画面から遷移（`theme_id` URLパラメータ必須）
- **表示内容:** 選択済みテーマ名、サブドメイン入力欄、運営者情報入力欄

#### 入力項目

| 項目 | 必須 | バリデーション |
|---|---|---|
| サブドメイン | ○ | 3〜50文字、小文字英数字とハイフンのみ |
| 運営者名 | ○ | 1〜100文字 |
| 運営者プロフィール | - | 500文字以内 |

#### 操作手順

1. テーマ選択画面から遷移（theme_idがURLに含まれている確認）
2. サブドメインを入力（例: `my-affiliate-site`）
3. 運営者名を入力
4. 運営者プロフィールを任意入力
5. 「サイトを生成する」ボタンをクリック
6. 成功時 → APIが生成ジョブをエンキュー → `/sites` に遷移
7. 失敗時 → エラーメッセージを表示

#### エラー表示

- サブドメイン形式不正: `小文字英数字とハイフンのみ使用可`
- サブドメイン重複: APIから `409 Conflict`
- theme_id未設定: フォームが正常に動作しない（空のテーマ名表示）

---

### 2-7. マイサイト一覧画面

- **URL:** `http://localhost:3000/sites`
- **認証:** ログイン必須
- **表示内容:** サイトカード一覧（サブドメイン・テーマ・ステータス・作成日・公開URL）

#### サイトステータス表示

| ステータス | アイコン | 色 | 意味 |
|---|---|---|---|
| `active` | ✓ CheckCircle | 緑 | 公開中・正常稼働 |
| `generating` | ○ Clock | 黄 | AI生成処理中 |
| `paused` | ⏸ PauseCircle | グレー | 一時停止中 |
| `error` | ! AlertCircle | 赤 | エラー発生 |

#### 操作できること

- 「新しいサイトを作る」ボタン → `/themes` に遷移（テーマ選択から開始）
- サイトカードの「↗ 開く」→ 会員サイトURL（`http://{subdomain}.localhost:4321`）を新タブで開く
- サイトが0件の場合: 空状態メッセージと「最初のサイトを作る」リンクを表示

---

### 2-8. 案件管理画面

- **URL:** `http://localhost:3000/offers`
- **認証:** ログイン必須
- **表示内容:** ジャンルフィルター、案件カード一覧（ASP・案件名・コミッション・承認率・EPC）

#### 操作手順

1. ジャンルタブ（すべて / 副業 / 転職 / AIツール / オンライン学習）でフィルター
2. 各案件カードで詳細（ASP・コミッション・承認率・EPC）を確認
3. 「詳細ページへ」リンクで案件元サイトを開く（`product_url` が設定されている場合）

#### データ表示

- コミッション: 金額（円）表示
- 承認率: パーセント表示
- EPC: 円/クリック表示
- ステータス `active` の案件のみ表示

---

### 2-9. 収益レポート画面

- **URL:** `http://localhost:3000/reports`
- **認証:** ログイン必須
- **表示内容:** サマリーカード4種、PV推移グラフ（折れ線）、収益推移グラフ（棒グラフ）

#### 表示される指標

| 指標 | 説明 |
|---|---|
| 総PV数 | 過去30日間の合計ページビュー |
| アフィリエイト収益 | 過去30日間の合計収益（円） |
| 成約件数 | コンバージョン数 |
| AI引用回数 | llms.txt経由のAI参照数 |

#### 操作できること

- グラフはレスポンシブ表示（Rechartsライブラリ使用）
- サイトが0件の場合: 空状態メッセージを表示

---

### 2-10. サイドバー（共通ナビゲーション）

- **表示場所:** ダッシュボード系全画面の左側
- **ナビメニュー:** ダッシュボード / テーマ選択 / マイサイト / 案件管理 / 収益レポート
- **現在ページ:** アクティブ状態（背景色変更）で強調表示
- **ユーザー情報:** ログイン中のメールアドレスを表示
- **ログアウト:** 「ログアウト」ボタン → JWT削除 → `/login` にリダイレクト

## 3. API一覧（Playwright MCPからの直接確認用）

| メソッド | エンドポイント | 認証 | 説明 |
|---|---|---|---|
| POST | `/api/v1/auth/register` | 不要 | 新規登録 |
| POST | `/api/v1/auth/login` | 不要 | ログイン (JWT取得) |
| GET | `/api/v1/auth/me` | 必要 | ログイン中ユーザー情報 |
| GET | `/api/v1/themes` | 不要 | テーマ一覧 |
| GET | `/api/v1/themes/:slug` | 不要 | テーマ詳細 |
| GET | `/api/v1/sites` | 必要 | マイサイト一覧 |
| POST | `/api/v1/sites` | 必要 | サイト作成 |
| GET | `/api/v1/sites/:id` | 必要 | サイト詳細 |
| POST | `/api/v1/generate/site/:siteId` | 必要 | サイト生成ジョブ起動 |
| GET | `/api/v1/offers` | 不要 | 案件一覧 |
| GET | `/api/v1/offers/:id` | 不要 | 案件詳細 |
| GET | `/api/v1/reports/summary` | 必要 | 収益サマリー |
| GET | `/api/v1/reports/daily` | 必要 | 日別レポート |

## 4. 画面遷移フロー

```
/ (ルート)
  ├─ 未ログイン → /login
  └─ ログイン済み → /dashboard

/login
  ├─ 認証成功 → /dashboard
  └─ 新規登録リンク → /register

/register
  ├─ 登録成功 → /dashboard
  └─ ログインリンク → /login

/dashboard (ログイン必須)
  ├─ テーマを選ぶ → /themes
  ├─ サイト管理 → /sites
  ├─ 案件を見る → /offers
  └─ レポート → /reports

/themes (ログイン必須)
  └─ テーマ選択 → /sites/new?theme_id=xxx&theme_name=xxx

/sites/new (ログイン必須)
  └─ 生成成功 → /sites

/sites (ログイン必須)
  └─ 新規作成 → /themes

/offers (ログイン必須)
/reports (ログイン必須)
```

## 6. 既知の注意事項

1. **AI生成機能:** `ANTHROPIC_API_KEY` が未設定の場合、サイト生成APIはエラーになる
2. **サブドメイン:** ローカル環境では `{subdomain}.localhost:4321` 形式
3. **収益レポート:** サイトが0件の場合、グラフは表示されない（空状態UI）
4. **案件管理:** ASP実連携は未実装（Phase 1完了後にA8.net / アクセストレードAPI連携予定）
5. **Stripe決済:** 未実装（Phase 3予定）
